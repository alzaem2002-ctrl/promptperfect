# ?? ComfyUI AnimateDiff Setup

Complete setup for running ComfyUI with AnimateDiff for AI video generation.

## ?? Features

- **Easy Setup**: Automated scripts for installation and configuration
- **Model Management**: Automatic download of required models
- **Workflow Templates**: Pre-configured AnimateDiff workflows
- **GPU Support**: Optimized for NVIDIA GPUs (CPU fallback available)

## ?? Requirements

### System Requirements
- **Python**: 3.10 or higher
- **GPU**: NVIDIA GPU with CUDA support (recommended)
- **Storage**: ~10GB for models
- **RAM**: 8GB minimum, 16GB recommended

### Software Requirements
- Git
- Python 3.10+
- CUDA Toolkit (for GPU support)

## ?? Quick Start

### 1. Clone This Repository

```bash
git clone <your-repo-url>
cd comfyui-animatediff
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Setup ComfyUI

```bash
python setup_comfyui.py
```

This will:
- Clone ComfyUI repository
- Install all dependencies
- Create necessary directories
- Check GPU availability

### 4. Download Models

```bash
python download_models.py
```

This downloads (~8GB total):
- Stable Diffusion v1.5 checkpoint
- VAE (Variational Autoencoder)
- AnimateDiff motion module

### 5. Start ComfyUI Server

```bash
python run_comfyui.py
```

Access the UI at: **http://localhost:8188**

## ?? Using AnimateDiff

### Load Workflow

1. Open ComfyUI in browser: http://localhost:8188
2. Load workflow: `workflows/animatediff_workflow.json`
3. Customize prompts and settings
4. Click "Queue Prompt" to generate

### Example Prompts

**Positive:**
```
stunning cinematic landscape, mountains, sunrise, 8k, masterpiece, high quality
```

**Negative:**
```
low quality, worst quality, blurry, watermark, text, deformed
```

### Output

Generated videos are saved to: `ComfyUI/output/`

## ?? Configuration

### Environment Variables

```bash
export COMFYUI_PROJECT_DIR="/path/to/custom/location"
```

### Server Options

```bash
# Run on different port
python run_comfyui.py --port 8080

# Localhost only (no external access)
python run_comfyui.py --no-listen
```

## ?? Troubleshooting

### GPU Not Detected

If you have NVIDIA GPU but it's not detected:
```bash
# Check CUDA installation
nvidia-smi

# Install CUDA Toolkit
# https://developer.nvidia.com/cuda-downloads
```

### Out of Memory

Reduce batch size in workflow:
- Edit node 6 (Empty Latent): `batch_size: 8` (instead of 16)

### Models Not Downloading

Download manually:
- [Stable Diffusion v1.5](https://huggingface.co/runwayml/stable-diffusion-v1-5/blob/main/v1-5-pruned-emaonly.safetensors)
- [VAE](https://huggingface.co/stabilityai/sd-vae-ft-mse-original/blob/main/vae-ft-mse-840000-ema-pruned.safetensors)
- [AnimateDiff](https://huggingface.co/guoyww/animatediff/blob/main/mm_sd_v15_v2.ckpt)

Place in respective folders under `ComfyUI/models/`
