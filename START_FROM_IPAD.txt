2️⃣  اذهب إلى: colab.research.google.com

3️⃣  أنشئ notebook جديد
    - File → New notebook

4️⃣  فعّل GPU (مهم!)

    - Hardware accelerator → GPU
    - Save

5️⃣  افتح الدليل الكامل:
    📖 اقرأ: IPAD_GUIDE.md

6️⃣  انسخ والصق الأكواد (10 خلايا)

    - جاهزة للنسخ واللصق مباشرة!

8️⃣  احصل على الرابط وافتحه

9️⃣  أنشئ فيديوك الأول! 🎬
