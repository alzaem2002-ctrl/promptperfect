# 📤 دليل رفع Notebook إلى Google Colab

## الطريقة الأسهل ⭐ (30 ثانية)

### 1️⃣ حمّل الملف
```bash
# الملف موجود في:
/workspace/comfyui-ipad-system/ComfyUI_Colab.ipynb
```

انسخه إلى جهازك

### 2️⃣ اذهب إلى Colab
افتح: https://colab.research.google.com

### 3️⃣ ارفع الملف
1. اضغط **File** → **Upload notebook**
2. اسحب الملف `ComfyUI_Colab.ipynb`
3. أو اضغط **Choose File** واختره

### 4️⃣ فعّل GPU
1. **Runtime** → **Change runtime type**
2. اختر **T4 GPU**
3. **Save**

### 5️⃣ شغّل!
اضغط **Runtime** → **Run all**
